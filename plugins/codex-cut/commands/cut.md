# /video cut

Create a purposeful edit from a timeline or raw footage.

## Usage

```txt
/video cut 45s trailer for Product Hunt
/video cut 30s youtube short from ./raw-demo.mp4
```

## Behavior

1. Define target platform and duration.
2. Select moments based on transcript, UI action, audio peaks, or user notes.
3. Build scenes with hook, proof, demo, CTA.
4. Add zooms and transitions only where they clarify the product.
5. Save a Timeline IR before rendering.

## Output

- `timeline.json`
- `src/Video.tsx`
- draft export in the chosen platform preset
