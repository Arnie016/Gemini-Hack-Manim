# NorthStar Product Decisions To Lock

These are the next product decisions that affect architecture, pricing, and API integrations.

1. Should hosted NorthStar always include platform OpenAI credits, or should paid tiers allow cheaper bring-your-own-key mode?
2. What is the exact free trial limit: videos, render minutes, tokens, or a blended credit unit?
3. Which upload formats are launch-critical: PDF, MD, PNG/SVG, MP4, audio, or all of them from day one?
4. Should source-grounded generation require user confirmation of extracted facts before planning?
5. Do we store generated Manim code as the canonical artifact, or the scene plan plus code plus render bundle together?
6. Which share target launches first: public link, YouTube Shorts, TikTok, X, Reddit, or downloadable package?
7. Should public share pages show full code, only the video, or a remixable scene summary?
8. What should the Codex/NorthStar harness be allowed to edit automatically inside a user project?
9. Should long videos run as queued backend jobs only, or should local desktop users be able to render directly on their Mac?
10. What compliance/privacy promise do we make for uploaded cheat sheets, lecture notes, and private study materials?
